## 时间线

**初中** — 在学校的 Arduino 社团里第一次接触电路、编程和传感器，做过循迹小车一类的项目。那时候我其实说不清"嵌入式"是什么意思，只知道写几行代码、接几根线，小车就真的会拐弯。

**高中** — 自学 Linux、Python 与鸿蒙 ArkTS 开发，考取华为鸿蒙应用开发者认证；同时也折腾安卓 Root，反复刷机、变砖、救砖。现在回头看这些学习比较零散，但养成了两个习惯：遇到问题先自己查，以及不看到东西真跑起来不算学会。

**2025.09** — 进入西南科技大学，就读制药工程专业。这个结果与我的兴趣不太一致，因此从入学起就在往计算机和电子信息方向靠：旁听课程、加技术社团、找项目。

**2025.10** — 加入"一生一芯"学习小组，自学 Verilog 与 RISC-V，做到 E5 阶段 RTL 仿真。这是我最"硬"的一段自学经历：没有实验指导书、没有期末考试，只有一个目标和远超我水平的代码库。

**2026.03** — 开始接触跨专业的技术实践环境，同时旁听自动化专业的《电路分析基础》并跟进到第七章。也是在这个阶段意识到，申请什么都需要"你做出过什么"，于是开始主动找老师和项目。

**2026.04** — 开始参与医学影像方向的项目开发，负责的部分从"跟着学"变成了"我来写"。第一次知道一张超声图像的分割标注怎么做，也第一次知道一个分类模型的分数可以被数据划分方式"刷"出来。

**2026.05 – 07** — 校赛二等奖、省级大创立项；随后是省级二等奖与国家级三等奖。同期完成 MNIST 七模型对比的完整工程。

**2026.07 – 08** — 暑假留在学校，把时间押在工程能力上：把 Agent 用进真实的科研流程（三万篇论文的语料摄取、多智能体协作系统），补部署与运维的课，并且碰了碰国产 AI 芯片的算子赛题。

**2026.09** — 转入电子信息工程（卓越）班，同时参加高教社杯全国大学生数学建模竞赛。转专业这件事我从大一入学就在准备。
