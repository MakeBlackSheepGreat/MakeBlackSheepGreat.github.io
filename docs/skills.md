## 智能体系统

- **多智能体编排**：按角色（探索、实现、审查）拆分任务并并行执行；长周期任务采用进度落盘与中断续跑
- **工作流设计**：将文献处理、实验执行与结果整理组织为可重复运行的流水线
- **上下文与记忆管理**：将环境约束与失败经验沉淀为项目规则文件与记忆文件，降低重复试错成本
- **工具链开发**：面向智能体开发了 PDF 文献检索工具、技能模块与文档站，并基于开源项目构建了个人编码智能体

## 工程与部署

- **Linux**：日常开发环境；服务器服务部署、进程托管与日志排查
- **服务与网络**：反向代理、内网组网、隧道与公网访问、域名与 HTTPS 配置
- **Python 工程**：uv / venv 环境管理、依赖与版本问题排查、脚本与命令行工具开发
- **Git 与 GitHub**：分支与变基、历史清理、GitHub Actions 自动构建与发布
- **测试与交付**：界面全量自动化回归、发行包打包与跨机器验证
- **数据与检索**：向量检索、文档切片与知识库构建

## 研究方法

- **实验记录**：判定标准前置；失败实验与成功实验采用同一记录模板；配置与结论登记成表
- **可复现性**：数据划分、随机种子与评估脚本入库，保证换机可复现
- **评价指标**：熟悉医学影像常用评价体系（AUC、敏感度、特异度、精确率、F1）及其在临床场景中的含义与局限

## 工作方式

- **工具链**：Linux 环境开发，Python 环境使用 uv 管理，代码托管于 Git 与 GitHub，服务部署在自建服务器
- **与智能体协作**：将编码智能体作为长期协作工具，按角色拆分并行执行；每个项目维护规则文件与记忆文件，约束环境相关的重复问题
