# 获奖与立项


## 学科竞赛

::: card 2026 年度中国青年科技创新“揭榜挂帅”擂台赛 · 国家级二等奖
2026 年 10 月，共青团中央主办。赛题为面向颌骨骨髓炎的智能化荧光诊疗，发榜单位为成都科奥达光电技术有限公司。

参赛作品为《面向颌骨骨髓炎精准清创的智能化荧光诊疗平台及产业化应用》。作品形态是一套可离线运行的医学影像工作站软件，涵盖文件准入、病例管理、图像处理、AI 候选提示、人工标注、医生复核与证据导出，各环节落在同一条可追溯流程里。

输入支持白光与荧光 JPEG、单路或三视图 MP4、CBCT 与 STL 三维参考数据。输出为融合图、伪彩图、风险图、不确定性图和结构化证据包。平台把结果定位为术中参考信号与复核材料，保留医生复核这一最终判断环节。

技术栈为 Python 3.11 与 FastAPI 后端、Vue 3 前端、PyTorch 推理。三维渲染拆成独立的 Three.js 运行时，桌面端由 Electron 宿主打包，可离线分发。平台的整体设计与全部工程实现由本人独立完成，覆盖后端服务与数据契约、前端工作站交互、推理管线与模型适配层、三维运行时、测试体系与桌面发行打包。
:::

::: card 第十一届全国大学生生物医学工程创新设计大赛 · 国家级三等奖
2026 年 7 月，中国生物医学工程学会主办。

参赛作品为《基于超声影像的乳腺肿瘤良恶性分类辅助诊断系统设计》，同一作品先经校赛选拔后进入国赛。系统以乳腺超声图像为输入，输出病灶区域提示、良恶性判别与风险分层，同时给出模型关注区域。

技术上采用双模型互补集成与病灶区域引导的两段式推理。完整图分支保留采集背景与周围组织上下文；分割分支生成病灶掩膜，经连通域提取与边界扩展裁出感兴趣区域，再由同一套分类体系评估局部视角。两路证据在 logit 空间融合，并设面积门控：掩膜异常时回退到完整图结果。分类主干采用病例级五折交叉验证训练，同一患者的样本不跨折，以降低划分偶然性；推理阶段叠加多尺度裁剪与水平翻转的测试时增强。可解释性部分输出 Grad-CAM 关注区域，与分割掩膜、感兴趣区域裁剪一并展示，用于区分模型在看哪里与病灶在哪里。

本人承担软件开发与项目报告的技术部分：数据预处理与划分口径、分类与分割模型的训练评估、集成与融合流程、Grad-CAM 可视化、演示系统，以及报告中方法、实验与结果章节的撰写。其余工作由团队其他成员完成。
:::

::: card 第六届四川省大学生生物医学工程创新设计大赛 · 省级二等奖
2026 年 6 月，四川省教育厅主办。

参赛作品为《基于胸部 CT 的肺结节智能分类与可解释性恶性风险分级系统构建》，团队 4 人。系统以 DICOM 序列为输入，完成序列读取与排序、候选定位、感兴趣区域裁剪，输出恶性风险概率、低中高风险分级与结构化报告。

技术路线上没有直接用三维网络，而是采用 2.5D 六通道输入：围绕候选中心层抽取相邻若干层 CT，再拼接一张由分割网络生成的候选区域掩膜，作为结构先验提示分类器候选区域的位置。这样既保留层间上下文，又回避了三维网络在显存、推理延迟与部署复杂度上的代价。分类主干经多轮筛选确定；训练采用患者级划分，避免同一患者跨折泄漏；引入概率校准，使输出概率可解释。系统另设独立的外部验证队列，仅用于评估鲁棒性，不参与训练、阈值选择与校准调参。可解释性方面，候选定位、区域掩膜与 Grad-CAM 分开展示，用于区分候选在哪一层、结构先验是什么、模型关注哪里。肺内存在多个候选时，系统逐个给出证据，不压缩为单一患者级结论。

本人承担软件开发与项目报告的技术部分：数据处理与模型实验、训练与评估流程、可解释性输出，以及报告中方法、实验与结果章节的撰写。其余工作由团队其他成员完成。该作品同期获批省级大学生创新训练计划项目立项。
:::
